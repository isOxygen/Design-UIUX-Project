# 04: Problem definition and alternatives

As a returning subscriber, I want to find setup details without confusing them with renewal. Stakeholders: subscriber (complete setup), support (less manual help), product owner (clear self-service), engineering (safe configuration display). How might we separate viewing from acting? How might we help users choose a setup format? How might we keep upgrades visible without distracting from setup? Candidate ideas: long page, status shortcut, dedicated tabs, sticky nav, connection wizard, contextual help, combined connection card, and renamed menu. Estimated priorities: high impact/easy: tabs and clearer labels; high impact/harder: wizard and sticky nav; lower impact/easy: contextual help and shortcut; lower impact/harder: combined card and full one-page rework. Priorities are design estimates pending research.
