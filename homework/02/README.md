# 02: Research, persona and journey

Interview one returning subscriber about the last time they connected a second device, what they looked for, and where they hesitated. Keep notes anonymous and label quote, observation and interpretation. Working persona: a returning subscriber setting up another device; familiarity with configuration formats is unknown. Journey: check service → look for setup → choose format → get result. This is a hypothesis, not a research-based persona or affinity map.
