# 01: Problem and opportunity

A returning subscriber who switches devices needs setup details but may start by monitoring the service. Monitoring and setup serve different goals. Putting them in the same view makes usage information compete with multiple connection and management options. The user's goal is to connect a device; the service goal is independent self-service. Scope: mobile, no live credentials. The first pitch is the Status/Manage split. Observe whether a user finds an assigned setup entry unaided within 30 seconds.
